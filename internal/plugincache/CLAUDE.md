# internal/plugincache — agent notes

- **This is a thin, synchronous path/stat layer.** The only real work is `filepath.Join` and `os.Stat`. No I/O-heavy operations or cross-process boundaries. Instrumentation is minimal per logging-telemetry.md: a single `slog.DebugContext` entry logging the resolved path on `Exists`, nothing more. The overhead of an OTel span would exceed the actual work being done.

- **No import of `internal/telemetry`.** Per the assessment above, a single `os.Stat` call does not warrant a span. The `DEBUG` log on the path is sufficient for troubleshooting.

- **Sanitization is deterministic, not cryptographic.** The sanitization scheme (replacing separators with `_`) is simple, deterministic, and collision-resistant for the realistic input space (git-forge addresses, semver versions, `<os>_<arch>` platform keys). It is not intended to be a security boundary — it exists purely to make caller-supplied strings filesystem-safe.

- **`pathSegment` is applied to ALL THREE caller-supplied components, not just `source`.** It originally sanitized only the source, on the reasoning that a git-forge address is the one obviously slash-bearing input. But `version` and `platform` are equally caller-supplied — both come from a lock-file row — and `filepath.Join` *resolves* a `..` component rather than treating it as a literal name, so either one could push the resolved path outside `cacheDir`. That is **not** a privilege boundary (the lock file is already the source of truth for what is allowed to run, and `registry.VerifyChecksum` validates the binary against that same row, so an attacker who controls the lock file has already won) — it is a correctness one: a malformed version silently resolving outside the cache reports "not installed" instead of "your lock file is malformed." Every well-formed input is unaffected, so no real cached path moved. `TestBinaryPath_everyComponentStaysInsideCacheDir` covers it, and `TestBinaryPath_wellFormedInputIsUnchanged` guards the no-op property. Note the assertion is on path *components* equal to `.`/`..`, not on a `..` substring — `.._.._tmp` is an ordinary literal directory name.

- **`Exists` distinguishes "not found" from "can't tell".** The function returns `(false, nil)` for `os.IsNotExist` (clear signal that the binary is not installed) and `(false, err)` for any other stat error (permission denied, etc.), allowing the caller to make an informed decision about how to proceed.

- **Platform string is built from `runtime.GOOS` and `runtime.GOARCH`.** No special handling — just a simple concatenation with `_` separator, matching the canonical platform key format used in lock files.
